## FAQ

### What exactly does VideoPatch do?

VideoPatch modifies supported video editor installations to unlock premium features, remove watermarks, and activate professional tools that are normally behind a paywall.

### Is it safe to use VideoPatch?

VideoPatch is designed as a standalone utility. You should always download it from trusted sources and scan it with anticomponent software before running any executable.

### Which video editors are supported?

VideoPatch currently supports CapCut, DaVinci Resolve, Filmora, VideoPad, HitFilm, and Movavi. Support for additional editors may be added in the future.

### Do I need to uninstall my video editor first?

No, VideoPatch works by modifying the existing installation files of your video editor. You should not need to uninstall it.

### Will this affect future updates of my video editor?

Yes, applying the patch may be undone by official software updates. You may need to re-apply the patch after a major update from the software developer.

### I'm having trouble extracting the ZIP. What should I do?

Ensure you are using the correct password: videopatch (all lowercase). Try using a different extraction tool like 7-Zip if the default Windows extractor fails.

Please open an issue on the GitHub repository's Issues tab. Provide a detailed description of your problem, your operating system version, and the editor you are trying to patch.
